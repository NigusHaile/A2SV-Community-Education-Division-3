
# A2SV Community Education — Data Structures & Algorithms Series

A complete Data Structures and Algorithms learning track adapted from the
**A2SV (Africa to Silicon Valley) Community Education** program. This
repository collects 32 structured lectures that take a learner from Python
basics all the way to advanced topics like graphs and dynamic programming,
with a strong emphasis on competitive programming, technical-interview
problem solving and additional leetcode exercises.

## 📚 What's inside

The series is organized into four progressive stages:

**1. Foundations & Mindset**
- Kickoff and program orientation
- Focus, time management, and planning
- Best practices for learning and coding
- The 7 Steps of Highly Effective Problem Solving

**2. Python & Complexity**
- Python basics: conditionals and loops
- Core data structures: lists, tuples, sets, dictionaries
- Time and space complexity (with variants)
- Best coding practices and code review

**3. Core Data Structures & Techniques**
- Arrays, lists, and matrices
- Sorting fundamentals
- Two pointers and sliding window
- Prefix sums
- Stacks, queues, and monotonic structures (Parts I & II)
- Linked lists
- Recursion (Parts I & II)
- Numerics
- Greedy algorithms

**4. Advanced Topics**
- Trees (Parts I & II) and Tries
- Binary search
- Graphs, shortest paths, DFS, BFS
- Heaps
- Dynamic Programming (bottom-up approach)
